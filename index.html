Мой гардероб

Сначала один раз подключи хранилище.

Это займёт 2 минуты, инструкция во вкладке «Настройка».

Снимай вещь целиком при дневном свете на светлом фоне: на кровати, на двери, на вешалке. Одна вещь на фото.

Загружено сейчас

Когда загрузишь всё, напиши Claude в чате: «оцени гардероб». Оценки и образы появятся во вкладках «Гардероб» и «Образы».

Пазлы к гардеробу

Вещи, которые стоит докупить, чтобы твои вещи заиграли. Сверху то, что подойдёт к большему числу твоих вещей. Ссылки ведут на поиск в магазинах.

Подключить хранилище

Фото сохраняются в твой приватный репозиторий wardrobe-data на GitHub. Их видишь только ты и Claude. Чтобы телефон мог туда загружать, нужен ключ доступа. Делается один раз.

1. Создать ключ на GitHub
  1. Нажми кнопку выше и войди в аккаунт ketrinprisyazna-eng. Название, срок и права уже заполнены.
  2. В блоке Repository access выбери Only select repositories и отметь wardrobe-data.
  3. Проверь, что в Permissions у Contents стоит Read and write. Если нет, выбери.
  4. Нажми зелёную кнопку Generate token внизу, затем значок копирования рядом с ключом.
  5. Вернись сюда, вставь ключ в поле ниже и нажми «Сохранить и проверить».

Ключ хранится только в браузере этого телефона и никуда, кроме GitHub, не отправляется. Никому его не показывай.

Автоматическая оценка (Gemini)

С ключом Gemini каждая вещь оценивается сразу после фото, без Claude. Бесплатно в пределах лимита Google.

  1. Открой aistudio.google.com/apikey и войди в Google-аккаунт.
  2. Нажми Create API key и скопируй ключ (начинается с AIza).
  3. Вставь его ниже и нажми «Сохранить и проверить».

Ключ хранится только в этом браузере. На бесплатном тарифе Google может использовать фото для улучшения моделей, поэтому отправляй только фото одежды, без селфи.

Иконка на главном экране

В Chrome нажми ⋮ справа вверху, затем «Добавить на главный экран». Гардероб будет открываться как приложение.
